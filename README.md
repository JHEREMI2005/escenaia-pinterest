# EscenaIA Pinterest site

Static landing page and privacy policy prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository named `escenaia-pinterest`.
2. Upload the files in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub to provide a URL similar to `https://YOUR-USER.github.io/escenaia-pinterest/`.

Use that URL in Pinterest as the company/application website, and append `privacy.html` for the privacy-policy URL.
